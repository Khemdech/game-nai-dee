# Game-Nai-Dee (เกมไหนดี)

เว็บค้นหาเกม ดูรายละเอียด บันทึกเกมโปรด และเปรียบเทียบเกม สำหรับ **CS319 Mini Project 2** ใช้ข้อมูลจาก **RAWG Video Games Database**

## ทดลองใช้งาน

[เปิดเว็บไซต์ Game-Nai-Dee](https://game-nai-dee.vercel.app/)

## ความสามารถของโปรแกรม

| หน้า | สิ่งที่ทำได้ |
|---|---|
| Discover | แสดงเกมสูงสุด 20 รายการ ค้นหาด้วยชื่อ กรองแนวเกม 19 ตัวเลือก เปิดรายละเอียด และเลือกเกมเปรียบเทียบ |
| Game Details | แสดงรูป คำอธิบาย แนวเกม วันวางจำหน่าย แพลตฟอร์ม คะแนน RAWG และ Metacritic พร้อมเพิ่ม/ลบเกมโปรดและเกมเปรียบเทียบ |
| Collection | แสดงเกมโปรด เปิดรายละเอียด และนำเกมออกจากรายการ โดยจำรายการหลังรีเฟรช |
| Compare | ค้นหา เลือก และเปลี่ยนเกมในหน้าเดียวกัน เปรียบเทียบเกมไม่ซ้ำสูงสุด 2 เกมในตารางซ้าย–ขวา พร้อมนำออกหรือล้างรายการ |
| About | แสดงข้อมูลสมาชิก 2 คน หน้าที่รายบุคคล หน้าที่ร่วมกัน เทคโนโลยี และเครดิต RAWG |

หน้า Discover, Game Details, Collection และ Compare มี Skeleton ระหว่างโหลดข้อมูล ส่วนช่องค้นหา Compare มี Loading Spinner พร้อมสถานะข้อมูลว่างและข้อผิดพลาดที่กดลองใหม่ได้ มีการตรวจ ID เกมและหน้า 404 สำหรับเส้นทางที่ไม่มีอยู่ ใช้ธีมขาว–น้ำเงินและฟอนต์ Outfit กับ Anuphan ผ่าน Google Fonts

## สถานะระหว่างโหลดข้อมูล

- Discover แสดงการ์ด Skeleton 6 ใบก่อนรายการเกมพร้อม
- Game Details แสดงโครงรูปปก ชื่อ ข้อมูล และคำอธิบาย
- Collection แสดง Skeleton แยกตามเกมโปรดแต่ละรายการ
- Compare แสดง Skeleton ของฝั่งที่กำลังโหลด ส่วนช่องค้นหามี Spinner ระหว่างรอคำค้นและผล API
- ใช้ classes ของ DaisyUI ที่ติดตั้งอยู่แล้ว และมีข้อความสำหรับโปรแกรมอ่านหน้าจอ
- เมื่อมีแคชสด ข้อมูลอาจแสดงทันทีโดยไม่เห็น Skeleton หากต้องการตรวจ ให้เปิด Network ใน DevTools เลือก 3G แล้วรีเฟรชหน้า เมื่อเสร็จให้กลับเป็น No throttling

## สิ่งที่ต้องเตรียม

1. **[Node.js 24 LTS](https://nodejs.org/en/download)** พร้อม npm — ใช้ติดตั้งแพ็กเกจและเปิดเว็บ เครื่องที่ตรวจโปรเจกต์ใช้ Node.js 24.14.0 และ npm 11.9.0
2. **เว็บเบราว์เซอร์** เช่น Chrome หรือ Edge และอินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจ โหลดข้อมูลเกม รูปภาพ และฟอนต์
3. **RAWG API key ของตนเอง** จาก [RAWG API](https://rawg.io/apidocs)
4. **[Git](https://git-scm.com/downloads)** เฉพาะกรณีใช้คำสั่ง clone; หากดาวน์โหลด ZIP สามารถข้ามได้
5. โปรแกรมแก้โค้ด เช่น VS Code เป็นตัวเลือกสำหรับแก้ไขโปรเจกต์ ไม่จำเป็นต่อการเปิดเว็บผ่าน Terminal

React, Vite, TypeScript, Router, Query, Zustand, Tailwind, DaisyUI และ ESLint อยู่ใน `package.json` แล้ว ติดตั้งทั้งหมดด้วย `npm ci` ครั้งเดียว ไม่ต้องติดตั้งแยกหรือแบบ global และไม่ต้องติดตั้งฐานข้อมูลหรือเซิร์ฟเวอร์ backend เพิ่ม

## ติดตั้งและเปิดใช้งาน

### 1. ดาวน์โหลดโปรเจกต์

ดาวน์โหลด ZIP จาก GitHub แล้วแตกไฟล์ หรือใช้:

```bash
git clone https://github.com/Khemdech/game-nai-dee.git
cd game-nai-dee
```

เปิด Terminal ในโฟลเดอร์ที่มี `package.json` แล้วตรวจว่า Node.js และ npm พร้อมใช้งาน:

```bash
node --version
npm --version
```

### 2. ติดตั้งแพ็กเกจ

```bash
npm ci
```

คำสั่งนี้ติดตั้งตาม `package-lock.json` และสร้าง `node_modules/` ให้เอง หากเพิ่งติดตั้ง Node.js แล้ว Terminal ยังไม่รู้จักคำสั่ง ให้ปิด Terminal แล้วเปิดใหม่

### 3. ตั้งค่า RAWG API key

สร้างไฟล์ชื่อ `.env.local` ในโฟลเดอร์เดียวกับ `package.json` แล้วใส่:

```dotenv
VITE_RAWG_API_KEY=YOUR_RAWG_API_KEY
```

แทน `YOUR_RAWG_API_KEY` ด้วย key ของตนเอง ไม่ใส่ placeholder ตามตัวอย่างไว้ใช้งานจริง ไฟล์นี้ไม่อยู่ใน GitHub ผู้ที่ดาวน์โหลดโปรเจกต์จึงต้องสร้างเอง และระวังอย่าให้ชื่อไฟล์กลายเป็น `.env.local.txt`

ค่า `VITE_` ถูกใช้ในโค้ดฝั่งเบราว์เซอร์ จึงมองเห็นได้จากเว็บที่รันอยู่ แม้ไฟล์ `.env.local` จะถูก Git ignore ก็ตาม ไม่ควรนำ key จริงมาใส่ใน README หรือ commit

### 4. เปิดเว็บ

```bash
npm run dev
```

เปิด URL ที่ Terminal แสดง ปกติคือ `http://localhost:5173` หากพอร์ตถูกใช้งาน Vite อาจเลือกพอร์ตถัดไป หยุดเว็บด้วย `Ctrl+C` และหากเปลี่ยน `.env.local` ต้องหยุดแล้วเริ่มคำสั่งใหม่

บน Windows PowerShell หากพบข้อความว่าไม่อนุญาตให้รัน `npm.ps1` ให้ใช้ `npm.cmd` เช่น `npm.cmd ci` และ `npm.cmd run dev`

## วิธีใช้งาน

1. หน้า **Discover**: พิมพ์ชื่อเกมแล้วกด Search หรือ Enter เลือกแนวเกมจาก dropdown เพื่อกรองเพิ่ม
2. กด **View details** เพื่ออ่านรายละเอียด กด **Add to Favorite** เพื่อบันทึก แล้วดูรายการที่ **Collection**
3. เลือกเกมเปรียบเทียบจาก Discover/Details หรือเปิด **Compare** แล้วค้นหาฝั่งซ้ายก่อน ตามด้วยฝั่งขวา
4. การค้นหาใน Compare ต้องพิมพ์อย่างน้อย 2 ตัวอักษรและหยุดพิมพ์ 500 ms แสดงผลสูงสุด 5 รายการ กดชื่อเกมเพื่อเลือกหรือเปลี่ยนเกมของฝั่งนั้น
5. ดูข้อมูลทีมและหน้าที่ที่รับผิดชอบได้ที่ **About**

## การเก็บข้อมูลและแคช

- **TanStack Query** เก็บข้อมูลที่ได้จาก API ในหน่วยความจำ แยกตามคำค้น/แนวเกมหรือ ID เกม และกำหนดให้ข้อมูลสด 5 นาที
- เมื่อกลับมาดูข้อมูลเดิมที่ยังมีแคชสด จะใช้ข้อมูลเดิมได้ การค้นหาคำใหม่หรือเปิดเกมที่ไม่มีแคชต้องเรียก API
- เมื่อข้อมูลเก่าแล้ว อาจโหลดใหม่เมื่อกลับเข้าหน้า กลับมาโฟกัสแท็บ หรือเชื่อมต่ออินเทอร์เน็ตใหม่ ไม่ได้ตั้งเวลาเรียก API ทุก 5 นาที
- เมื่อ F5 หรือเปิดแท็บใหม่ แคชในหน่วยความจำเริ่มใหม่ จึงต้องโหลดข้อมูลเกมของหน้าที่เปิดอีกครั้ง
- **Zustand Persist** บันทึกเฉพาะ ID ของเกมโปรดและเกมเปรียบเทียบลง `localStorage` ไม่บันทึกรายละเอียดเกมทั้งก้อน การกดเพิ่ม/ลบรายการเป็นการเปลี่ยนข้อมูลในเครื่อง ไม่ส่ง POST ไป RAWG
- รายการที่บันทึกผูกกับเบราว์เซอร์และที่อยู่เว็บเดิม ไม่ซิงก์ข้ามเครื่องหรือบัญชีผู้ใช้ และอาจหายเมื่อล้างข้อมูลเว็บไซต์

## ขอบเขตและข้อจำกัด

- แสดงผลค้นหาหน้าแรกสูงสุด 20 เกม ยังไม่มีการเปลี่ยนหน้าหรือโหลดเพิ่ม
- Compare เลือกได้ 2 เกม เมื่อรายการว่างต้องเลือกซ้ายก่อน และเมื่อลบเกมซ้าย เกมขวาจะเลื่อนมาเป็นซ้าย
- คำค้นและแนวเกมใน Discover เริ่มใหม่เมื่อออกจากหน้าแล้วกลับมา
- รูป คะแนน และรายละเอียดขึ้นอยู่กับ RAWG เว็บไม่ได้เก็บข้อมูลเกมไว้ใช้งานออฟไลน์

## การนำขึ้น Hosting

ตั้งค่าตัวแปร `VITE_RAWG_API_KEY` บนบริการที่ใช้ก่อน build ใช้คำสั่ง build `npm run build` และโฟลเดอร์ผลลัพธ์ `dist` ต้องตั้ง SPA fallback ให้ URL เช่น `/games/3498` กลับไป `index.html` เมื่อเปิดโดยตรง และ build/deploy ใหม่เมื่อเปลี่ยนค่า env

`npm run preview` ใช้ตรวจผล build ในเครื่อง ไม่ใช่ขั้นตอนเผยแพร่เว็บไซต์
