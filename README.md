# Game-Nai-Dee (เกมไหนดี)

เว็บแอปพลิเคชันค้นหาเกม ดูรายละเอียด บันทึกเกมโปรด และเปรียบเทียบเกม พัฒนาสำหรับ **CS319 Mini Project 2** โดยใช้ข้อมูลจาก **RAWG Video Games Database**

## ความสามารถของโปรแกรม

### Discover — ค้นหาเกม

- แสดงรายการเกมจาก RAWG ครั้งละสูงสุด 20 เกม พร้อมรูปปก ชื่อ แนวเกม และคะแนน
- ค้นหาชื่อเกมด้วยการพิมพ์แล้วกด Search หรือ Enter
- กรองด้วย dropdown แนวเกม 19 ตัวเลือกและ All Games โดยใช้ร่วมกับคำค้นได้
- เปิดหน้ารายละเอียด หรือเลือกเกมสำหรับเปรียบเทียบจากการ์ดได้โดยตรง
- แสดงจำนวนเกมที่เลือกเปรียบเทียบ พร้อมปุ่มล้างรายการและลิงก์ไปหน้า Compare

### Game Details — รายละเอียดเกม

- โหลดข้อมูลตาม ID เกมใน URL
- แสดงรูปปก คำอธิบาย แนวเกม วันวางจำหน่าย แพลตฟอร์ม คะแนน RAWG และคะแนน Metacritic เมื่อมีข้อมูล
- เพิ่มหรือนำเกมออกจากรายการโปรดและรายการเปรียบเทียบ
- แยกกรณี ID ไม่ถูกต้อง ไม่พบเกม และการโหลดข้อมูลผิดพลาด

### Collection — เกมโปรด

- แสดงเกมที่บันทึกไว้ พร้อมลิงก์ดูรายละเอียดและปุ่มนำออก
- เก็บรายการ ID ใน localStorage จึงยังอยู่หลังรีเฟรชบนเบราว์เซอร์และที่อยู่เว็บเดิม
- แสดงข้อความแนะนำเมื่อยังไม่มีเกมโปรด

### Compare — เปรียบเทียบเกม

- เลือกเกมไม่ซ้ำกันได้สูงสุด 2 เกม พร้อมนำออกหรือล้างทั้งหมด
- เพิ่มเกมได้จากหน้า Discover และหน้ารายละเอียดเกม แล้วเปิดหน้า Compare เพื่อดูตาราง
- ค้นหาและเลือกหรือเปลี่ยนเกมจากหน้า Compare ได้ทั้งสองฝั่ง โดยเลือกฝั่งซ้ายก่อนเมื่อรายการว่าง
- พิมพ์อย่างน้อย 2 ตัวอักษรและหยุดพิมพ์ 500 ms เพื่อค้นหา แสดงผลสูงสุด 5 รายการ และปิดปุ่มเกมที่เลือกอยู่แล้ว
- เปรียบเทียบแนวเกม วันวางจำหน่าย คะแนน RAWG, Metacritic และแพลตฟอร์ม
- แบ่งรูปและข้อมูลซ้าย–ขวาเท่ากัน โดยชื่อหัวข้ออยู่เต็มแถวเพื่อให้อ่านเทียบกันง่าย
- บันทึก ID ที่เลือกลง localStorage และโหลดรายละเอียดแต่ละเกมแยกกัน

### About — เกี่ยวกับโปรเจกต์

- แสดงข้อมูลสมาชิก เทคโนโลยีที่ใช้ และเครดิตแหล่งข้อมูล RAWG
- **ข้อมูลสมาชิก 2 คนยังเป็นข้อมูลตัวอย่าง และยังไม่ได้ใส่รูปจริง**

หน้าที่เรียก API มีสถานะกำลังโหลด ข้อผิดพลาด และปุ่มลองใหม่ พร้อมข้อความรองรับข้อมูลว่างหรือข้อมูลที่ขาด เว็บไซต์ใช้ธีมขาว–น้ำเงินและจัดหน้าสำหรับจอขนาดต่าง ๆ โดยโหลดฟอนต์ Noto Sans Thai ผ่าน Google Fonts และมีฟอนต์สำรองเมื่อโหลดไม่ได้

## วิธีใช้งานโดยย่อ

1. เปิด Discover แล้วพิมพ์ชื่อเกม กด Search หรือ Enter; เลือกแนวเกมจาก dropdown เพื่อกรองเพิ่ม
2. กด View details เพื่ออ่านรายละเอียด และกดปุ่มบันทึกเกมโปรดเพื่อเก็บไว้ใน Collection
3. กดเลือกเปรียบเทียบบนการ์ดหรือหน้ารายละเอียดให้ครบ 2 เกม แล้วเปิด Compare
4. หรือเปิด Compare โดยตรง ค้นหาเกมฝั่งซ้ายแล้วเลือก ตามด้วยฝั่งขวา; ค้นหาใหม่ในฝั่งที่ต้องการเพื่อเปลี่ยนเกมโดยไม่เปลี่ยนอีกฝั่ง
5. เปิด Collection เพื่อดูเกมที่บันทึกไว้ และ About เพื่อดูข้อมูลทีมกับแหล่งข้อมูล

## การทำงานของข้อมูล

```text
ค้นหา / เลือกแนวเกม / เปิดรายละเอียด
    → Query Hook → ฟังก์ชัน API → RAWG
    → ตรวจรูปแบบข้อมูล → แคชของ TanStack Query → แสดงผล

เพิ่มเกมโปรด / เลือกเปรียบเทียบ
    → Zustand → บันทึกเฉพาะ ID ลง localStorage
    → ใช้ ID โหลดรายละเอียดผ่าน TanStack Query
```

- ข้อมูลเกมจาก API อยู่ใน TanStack Query ส่วน Zustand เก็บเฉพาะ ID ที่ผู้ใช้เลือก
- แคชรายการแยกตามคำค้นและแนวเกม ส่วนรายละเอียดแยกตาม ID
- การค้นหาหน้า Discover ส่งคำค้นเมื่อ submit; การเลือกแนวเกมเปลี่ยนตัวกรองทันที รายการแนวเกมกำหนดในโค้ด ไม่ได้โหลดจาก endpoint แนวเกม
- การค้นหาใน Compare ใช้ debounce 500 ms และใช้ query key รูปแบบเดียวกับ Discover จึงใช้แคชร่วมกันเมื่อคำค้นตรงกันและ Discover เลือก All Games
- API ขอรายการสูงสุด 20 เกมต่อคำขอ ส่วนกล่องค้นหา Compare แสดงเพียง 5 รายการแรกจากผลที่ได้
- ตั้ง `staleTime` ไว้ 5 นาที และลองใหม่อัตโนมัติอีก 1 ครั้งเมื่อคำขอล้มเหลว
- `staleTime` เป็นช่วงที่ข้อมูลถือว่ายังสด ไม่ใช่ตัวตั้งเวลาให้โหลดทุก 5 นาที
- แคช API อยู่ในหน่วยความจำของแท็บ ไม่ได้ persist ลง localStorage; รีเฟรชหรือเปิดแท็บใหม่จึงโหลดข้อมูลของหน้าที่เปิดใหม่ แม้ ID ที่บันทึกไว้ยังอยู่
- กลับมาดูข้อมูลเดิมระหว่างแคชยังอยู่และสดจะใช้แคช; คำค้น/เกมที่ยังไม่เคยโหลดต้องเรียก API ส่วน query ที่ไม่มีผู้ใช้จะถูกเก็บกวาดตาม gcTime ค่าเริ่มต้น 5 นาที

## การติดตั้งและเปิดใช้งาน

สภาพแวดล้อมที่ใช้พัฒนา: **Node.js 24.14.0 และ npm 11.9.0** ต้องมีอินเทอร์เน็ตและ RAWG API key เพื่อโหลดข้อมูลเกม

1. ดาวน์โหลดหรือ clone repository แล้วเปิด Terminal ในโฟลเดอร์ `game-nai-dee`
2. ติดตั้ง dependencies ตาม lockfile:

   ```bash
   npm ci
   ```

3. ขอ API key จาก [RAWG API](https://rawg.io/apidocs) แล้วสร้างไฟล์ `.env.local` ระดับเดียวกับ `package.json`:

   ```dotenv
   VITE_RAWG_API_KEY=YOUR_RAWG_API_KEY
   ```

   แทน `YOUR_RAWG_API_KEY` ด้วย key ของตนเอง และไม่ commit ไฟล์นี้ ค่า `VITE_` ถูกส่งไปยังเบราว์เซอร์ได้ จึงไม่ใช่ความลับฝั่งเซิร์ฟเวอร์

4. เปิดเว็บระหว่างพัฒนา:

   ```bash
   npm run dev
   ```

   เปิด URL ที่ Terminal แสดง โดยปกติคือ `http://localhost:5173` หากแก้ `.env.local` ให้หยุดเซิร์ฟเวอร์ด้วย Ctrl+C แล้วเริ่มใหม่

บน Windows PowerShell หาก `npm` ถูกบล็อกด้วยนโยบายรันสคริปต์ ให้ใช้ `npm.cmd` แทน เช่น `npm.cmd run dev`

## โครงสร้างโปรเจกต์

```text
public/              ไฟล์ static เช่น favicon และรูปสมาชิกเมื่อเพิ่มภายหลัง
src/
  api/               ฟังก์ชันเรียก RAWG และตรวจรูปแบบข้อมูล
  assets/            รูปและไฟล์ที่นำเข้าจากโค้ด
  components/        ส่วนแสดงผลที่ใช้ร่วมกัน
  hooks/             Hooks สำหรับ TanStack Query
  pages/             หน้าหลักและหน้ารองรับข้อผิดพลาด
  stores/            Zustand stores สำหรับ Favorites และ Compare
  types/             ชนิดข้อมูลเกมและ API response
  App.tsx            Layout เมนู และ footer
  main.tsx           จุดเริ่มต้นและ QueryClientProvider
  router.tsx         กำหนดเส้นทาง
  index.css          Styles กลาง
```

ไฟล์หลักของการค้นหาใน Compare คือ `src/hooks/useGameSearch.ts` สำหรับ debounce และ Query, `src/components/CompareGameSearch.tsx` สำหรับแสดงผล และ `src/stores/useCompareStore.ts` สำหรับเพิ่ม/เปลี่ยน/ลบ ID

## ขอบเขตปัจจุบัน

- ยังไม่มีระบบบัญชีผู้ใช้หรือการซิงก์รายการข้ามอุปกรณ์ การล้างข้อมูลเว็บไซต์อาจทำให้รายการที่บันทึกไว้หาย
- แสดงผลการค้นหาหน้าแรกสูงสุด 20 เกม ยังไม่มีปุ่มเปลี่ยนหน้าหรือโหลดเพิ่ม
- รายการแนวเกม 19 ตัวเลือกกำหนดไว้ในโค้ด จึงไม่อัปเดตอัตโนมัติเมื่อ RAWG เปลี่ยนรายการ
- Compare ใช้ array เรียงลำดับ: ต้องเลือกซ้ายก่อนขวาเมื่อรายการว่าง และเมื่อลบเกมซ้าย เกมขวาจะเลื่อนมาอยู่ซ้าย; การเปลี่ยนเกมด้วยช่องค้นหาใช้ `replaceCompare` จึงรักษาลำดับอีกเกมไว้
- ข้อมูลและรูปสมาชิกใน About ยังเป็นตัวอย่าง และชุด screenshots ยังรอจัดทำ โดยพักสองส่วนนี้ไว้ก่อนตามแผนปัจจุบัน
- คำค้น/แนวเกมเป็น state ของหน้า เมื่อออกจากหน้าแล้วกลับมาจะเริ่มค่าใหม่ แม้แคช API ของคำค้นเดิมอาจยังอยู่
- รูป คะแนน และรายละเอียดขึ้นอยู่กับข้อมูลและความพร้อมของ RAWG; คะแนน RAWG กับ Metacritic ใช้คนละมาตรวัด
- หากนำขึ้น hosting ต้องตั้ง SPA fallback เพื่อให้เปิด URL เช่น `/games/3328` โดยตรงได้

## ตรวจงานก่อนส่ง

- รัน `npm run lint` และ `npm run build` แล้วตรวจการใช้งานจริงด้วย `npm run dev`
- ลองค้นหา กรองแนวเกม เปิดรายละเอียด บันทึก/ลบเกมโปรด และเปรียบเทียบครบ 2 เกม รวมถึงรีเฟรชเพื่อตรวจการจำ ID
- ตรวจสถานะกำลังโหลด โหลดผิดพลาด/ลองใหม่ ไม่พบข้อมูล และการแสดงผลบนมือถือ แท็บเล็ต และเดสก์ท็อป
- เปลี่ยนข้อมูลตัวอย่างและรูปสมาชิกใน About เป็นข้อมูลจริง พร้อมระบุหน้าที่ที่ทำจริง
- เตรียมภาพหน้าจอครบ 5 หน้าและไฟล์ข้อมูลตัวอย่างตามโจทย์ โดยไม่ใส่ API key ในหลักฐานหรือไฟล์ส่ง
- การมีโค้ดครบหรือ build ผ่านยังไม่ยืนยันว่าผ่านข้อกำหนดทั้งหมด ต้องตรวจเทียบโจทย์และฝึกอธิบายโค้ดด้วยตนเอง

README นี้อธิบายสถานะจากโค้ดที่ตรวจเมื่อ 18 ตุลาคม 2026 การทดสอบ API/cache ก่อนหน้าเกิดก่อนเพิ่มช่องค้นหาใน Compare ทั้งสองฝั่ง จึงยังต้องตรวจการทำงานรวมของส่วนใหม่นี้ก่อนส่ง ไม่ใช่ผลรับรองว่าทุกกรณีผ่านแล้ว
